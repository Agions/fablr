【1. 软件简介】
--------------------------------------------------------------------------------
Fablr (剧工) 是一款基于 Tauri 2 + Rust + React 架构的本地优先（Local-first）
开源 AI 影视与短剧解说创作平台。
集成了素材智能拆条、多 Agent 剧本研磨、以文剪片 5 轨工作台、消重矩阵与剪映
草稿一键导出等核心能力，帮助创作者在数分钟内将长视频/短剧原片制作成高爆款
潜力的解说视频。

--------------------------------------------------------------------------------
【2. 4 步极速上手流程】
--------------------------------------------------------------------------------
1. 素材拆条 (Asset Hub)：
   - 打开客户端，点击首页「新建创作项目」；
   - 导入原片（支持 .mp4, .mov, .mkv 等）；
   - 本地引擎自动切分镜头片段并打上动作/悬疑场景标签。

2. 剧本研磨 (Script Studio)：
   - 切换到剧本工坊，选择爆款模板，点击「一键研磨剧本」；
   - 策划、编剧、审校 3 大 Agent 自动生成黄金前 3 秒 Hook、递进与高潮段落；
   - 可直接在卡片上修改台词，实时同步配音预估时长。

3. 以文剪片 (Workspace)：
   - 进入工作台，在「以文剪片」视图点击剧本段落即可智能吸附匹配切片至主轨道；
   - 在 5 轨时间轴（画面/画中画/解说配音/BGM/音效）按空格键实时视听预览。

4. 消重与导出 (Export Hub)：
   - 进入消重发布工坊，按需开启微调变速、动态噪点等消重策略；
   - 选择「导出剪映草稿工程」（直接注入本机剪映草稿，可无缝继续加花字特效）；
   - 或选择「本地硬件加速渲染」直接输出高清 MP4。

【3. 常用快捷键清单】
--------------------------------------------------------------------------------
[导航与通用]
  Cmd + 1 ~ 4 (Win: Ctrl + 1 ~ 4)  快速切换 4 大工坊
  Cmd + S     (Win: Ctrl + S)      立即强制保存项目
  Cmd + Z     (Win: Ctrl + Z)      撤销 (Undo)
  Cmd + Shift + Z (Win: Ctrl + Shift + Z) 重做 (Redo)
  Cmd + /     (Win: Ctrl + /)      打开快捷键帮助面板

[剪辑时间轴]
  Space                            播放 / 暂停视听预览
  S                                一键剪切光标处轨道切片
  Delete / Backspace               删除选中片段
  + / -                            放大 / 缩小时间轴刻度

[剧本工坊]
  Cmd + Enter (Win: Ctrl + Enter)  一键研磨 / AI 续写台词

【4. 常见问题排错 (FAQ)】
--------------------------------------------------------------------------------
Q1: macOS 提示「无法验证开发者」或「已损坏」？
    解决办法：打开终端（Terminal），复制并粘贴运行以下命令后按回车输入开机密码：
    sudo xattr -rd com.apple.quarantine /Applications/Fablr.app

Q2: 导出的剪映草稿在剪映中打开提示「素材丢失」？
    解决办法：剪映草稿通过路径引用原视频，导出后请勿移动或重命名原片。
    如已移动，在剪映提示弹窗中点击「重新定位」选中新位置的原片即可瞬间恢复。

Q3: AI 剧本生成提示网络超时？
    解决办法：前往「设置中心」检查大模型 API Key 与 Base URL 是否正确。
